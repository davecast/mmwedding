# mmwedding

Wedding announcement site (UI prototype) built with Next.js, Tailwind CSS v4 and Motion.
Layout based on the Neela template by WiselyThemes.

Requires Node 20.9+ (`.nvmrc` pins 24).

```bash
npm install
npm run dev
```

Agent skills (impeccable, Emil Kowalski's animation skills) live in `.claude/skills`.
